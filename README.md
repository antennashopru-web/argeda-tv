# ARGEDA TV

Проигрыватель IPTV для Android-приставок, телевизоров и телефонов (одно приложение, Android 5.0+).
Своих каналов в приложении нет: оно показывает плейлист провайдера, который добавил пользователь.

## Что умеет

- **Источники каналов:** ссылка M3U/M3U8, учётная запись Xtream Codes или файл `.m3u` с устройства. Можно добавить несколько плейлистов.
- **Ввод с телефона для ТВ:** пока открыт экран плейлиста, приставка показывает адрес `http://IP:порт/код`. На телефоне в той же сети открывают этот адрес и вставляют ссылку, чтобы не набирать её пультом. Сервер работает только при открытом экране, отвечает только из локальной сети и только по случайному коду.
- **Главный экран:** группы слева, каналы справа, поиск по названию и номеру. Есть разделы «Избранное» и «Недавние».
  На узком экране телефона группы выбираются кнопкой сверху.
- **Каналы 18+:** скрыты по умолчанию, открываются PIN-кодом и снова скрываются после выхода из приложения.
- **Просмотр (Media3/ExoPlayer):**
  - Форматы: HLS и MPEG-TS по HTTP/HTTPS. Если у ссылки нет `.m3u8`, приложение само определяет HLS.
  - Связь: при сбое три раза переподключается, понятно объясняет ошибки 401/403/404, а при отставании от эфира возвращается к нему.
  - Настройки: формат картинки (вписать / заполнить / растянуть) и выбор звуковой дорожки.
- **Телепрограмма XMLTV** (`.xml` или `.xml.gz`):
  - Источник: `url-tvg` из плейлиста или адрес, указанный вручную. У Xtream телепрограмма подключается сама.
  - Сопоставление каналов: по `tvg-id`, иначе по названию без «HD», «UHD» и пометок в скобках.
- **Пульт:**
  - ▲▼ и CH± — переключение каналов;
  - OK или ◀ — список каналов;
  - ▶ или INFO — сведения и кнопки;
  - цифры — переход по номеру канала;
  - долгое нажатие OK в списке — добавить в избранное.
- **Телефон:** касание — сведения, свайп вверх или вниз — другой канал, свайп вправо — список каналов.

## Данные и приватность

- **Где хранятся данные:** ссылки, логины и пароли провайдера лежат только в памяти приложения на устройстве (`allowBackup=false`).
- **Куда идут запросы:** приложение никуда их не отправляет, кроме серверов из плейлиста (поток, телепрограмма, логотипы).
- **Ключ подписи** хранится вне репозитория. Файлы `keystore.properties`, `*.jks` и `*.apk` перечислены в `.gitignore`.

## Сборка

```bash
ANDROID_SDK_ROOT=/путь/к/android-sdk ./gradlew assembleRelease
```

Release подписывается, если в корне проекта есть `keystore.properties` с полями:

- `storeFile` — абсолютный путь к ключу;
- `storePassword`;
- `keyAlias`;
- `keyPassword`.

Без этого файла собирается неподписанный APK. Готовый файл: `app/build/outputs/apk/release/app-release.apk`.

## Устройство кода

| Файл | Назначение |
|---|---|
| `M3u.java` | разбор M3U: `#EXTINF`, `#EXTGRP`, `#EXTVLCOPT`, заголовки после `\|`, `url-tvg`, `tvg-rec`/`catchup-days` |
| `Xtream.java` | Xtream Codes → список каналов (`player_api.php`) |
| `Epg.java` | потоковый разбор XMLTV, окно −3 ч … +36 ч |
| `Store.java` | плейлисты, кэш на диске, избранное, недавние, PIN |
| `MainActivity.java` | группы, каналы, поиск, меню |
| `PlayerActivity.java` | плеер, пульт, жесты, панели |
| `SourceActivity.java`, `LinkServer.java` | добавление плейлиста, ввод с телефона |

## Пока нет

- Просмотр архива (catchup): метки `tvg-rec` читаются, но в интерфейсе архива ещё нет.
- Сетка телепрограммы на несколько дней.
- Ссылки `rtmp://`, `rtsp://`, `udp://`.
