# ARGEDA TV

Проигрыватель IPTV для Android-приставок, телевизоров и телефонов (одно приложение, Android 5.0+).
Своих каналов в приложении нет: оно показывает плейлист провайдера, который добавил пользователь.

## Что умеет

- **Источники каналов:** ссылка M3U/M3U8, учётная запись Xtream Codes или файл `.m3u` с устройства. Можно добавить несколько плейлистов.
- **Ввод с телефона для ТВ:** пока открыт экран плейлиста, приставка показывает адрес `http://IP:порт/код`. На телефоне в той же сети открывают этот адрес и вставляют ссылку, чтобы не набирать её пультом. Сервер работает только при открытом экране, отвечает только из локальной сети и только по случайному коду.
- **Главный экран в стиле привычных IPTV-плееров:**
  - Колонки: группы, каналы (номер, логотип, текущая передача с полоской прогресса), справа окно предпросмотра и телепрограмма выбранного канала.
  - Предпросмотр: выбранный канал сразу играет в окне. На весь экран тот же поток переходит без новой загрузки (общий проигрыватель `Playback`).
  - Телефон в портретной ориентации: окно сверху, ниже вкладки «Каналы» и «Телепрограмма».
  - Окно предпросмотра выключается в меню.
  - Есть поиск по названию и номеру, разделы «Избранное» и «Недавние».
- **Архив (записи передач):**
  - Типы ссылок: `shift` (`?utc=…&lutc=…`), `flussonic` (`index-START-DUR.m3u8`, `timeshift_abs-START.ts`), Xtream Codes (`/timeshift/…`), `default`/`append` с шаблоном `catchup-source` (`{utc}`, `{lutc}`, `{duration}`, `{offset}`, `{Y}{m}{d}{H}{M}{S}`, `{utc:Y-m-d:H-M}`).
  - Выбор типа: определяется автоматически по `catchup`/`tvg-rec`, его можно сменить в настройках плейлиста.
  - Без телепрограммы: записи показаны часовыми отрезками за всю глубину архива.
  - Управление в записи: ◀ ▶ — перемотка, «Назад» — вернуться в прямой эфир. На полном экране текущую передачу можно смотреть с начала.
- **Каналы 18+:** скрыты по умолчанию, открываются PIN-кодом и снова скрываются после выхода из приложения.
- **Просмотр (Media3/ExoPlayer):**
  - Форматы: HLS и MPEG-TS по HTTP/HTTPS. Если у ссылки нет `.m3u8`, приложение само определяет HLS.
  - Связь: при сбое три раза переподключается, понятно объясняет ошибки 401/403/404, а при отставании от эфира возвращается к нему.
  - Настройки: формат картинки (вписать / заполнить / растянуть) и выбор звуковой дорожки.
- **Телепрограмма XMLTV** (`.xml` или `.xml.gz`):
  - Источник: `url-tvg` из плейлиста или адрес, указанный вручную. У Xtream телепрограмма подключается сама.
  - Сопоставление каналов: по `tvg-id`, иначе по названию без «HD», «UHD» и пометок в скобках.
  - Что хранится: только каналы плейлиста; прошлое — на глубину архива (не больше 7 дней), будущее — на 2 суток вперёд. Описания передач — на ближайшие сутки.
- **Пульт на главном экране:**
  - ▲▼ — выбор канала, он включается в окне;
  - OK — на весь экран;
  - ▶ — телепрограмма и записи;
  - ◀ — группы.
- **Пульт на полном экране:**
  - ▲▼ и CH± — каналы;
  - OK или ◀ — список каналов;
  - ▶ — сведения и кнопки (телепрограмма, избранное, формат, звук);
  - цифры — номер канала;
  - в записи ◀▶ — перемотка.
- **Телефон:**
  - касание канала включает его в окне, второе касание — на весь экран;
  - на полном экране свайп вверх или вниз — другой канал;
  - вправо — список, влево — телепрограмма;
  - в записи свайп влево или вправо — перемотка на 5 минут.

## Данные и приватность

- **Где хранятся данные:** ссылки, логины и пароли провайдера лежат только в памяти приложения на устройстве (`allowBackup=false`).
- **Куда идут запросы:** приложение никуда их не отправляет, кроме серверов из плейлиста (поток, телепрограмма, логотипы).
- **Ключ подписи** хранится вне репозитория. Файлы `keystore.properties`, `*.jks` и `*.apk` перечислены в `.gitignore`.

## Сборка

```bash
ANDROID_SDK_ROOT=/путь/к/android-sdk ./gradlew assembleRelease
```

Release подписывается, если в корне проекта есть `keystore.properties` с полями:

- `storeFile` — абсолютный путь к ключу;
- `storePassword`;
- `keyAlias`;
- `keyPassword`.

Без этого файла собирается неподписанный APK. Готовый файл: `app/build/outputs/apk/release/app-release.apk`.

### Автообновление

- Каждый push в `main` собирает подписанный APK и выпускает релиз `v1.2.N` с файлом `argeda-tv-КОД.apk` (код = 100 + номер сборки).
- Приложение раз в 6 часов (и по пункту меню «Проверить обновления») смотрит последний релиз, скачивает новую версию и предлагает установить. Android попросит один раз разрешить ARGEDA TV установку приложений.
- Обновление встаёт поверх только при той же подписи, поэтому релиз выпускается лишь при заданных секретах ключа (см. ниже). Ключ нельзя терять: без него придётся переустанавливать приложение у всех.

### Сборка на GitHub

Каждый push и pull request собирает APK в GitHub Actions (вкладка Actions → запуск → архив `argeda-tv-apk`).
Без секретов собирается отладочная версия `app-debug.apk`: её можно сразу поставить на приставку или телефон.
Чтобы получить подписанный release, добавьте в Settings → Secrets → Actions: `KEYSTORE_BASE64` (файл `.jks` в base64), `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`.

## Устройство кода

| Файл | Назначение |
|---|---|
| `M3u.java` | разбор M3U: `#EXTINF`, `#EXTGRP`, `#EXTVLCOPT`, заголовки после `\|`, `url-tvg`, `tvg-rec`/`catchup-days` |
| `Xtream.java` | Xtream Codes → список каналов (`player_api.php`) |
| `Epg.java` | потоковый разбор XMLTV: только каналы плейлиста, окно «глубина архива … +2 суток» |
| `Catchup.java` | ссылки на записи: shift, flussonic, xc, default, append |
| `Playback.java` | один проигрыватель на всё приложение: предпросмотр → полный экран без перезагрузки |
| `EpgAdapter.java` | список передач: «сейчас», «запись», дни |
| `Store.java` | плейлисты, кэш на диске, избранное, недавние, PIN |
| `MainActivity.java` | группы, каналы, поиск, меню |
| `PlayerActivity.java` | полный экран: пульт, жесты, список каналов, телепрограмма, перемотка записи |
| `SourceActivity.java`, `LinkServer.java` | добавление плейлиста, ввод с телефона |
